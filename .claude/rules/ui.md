# UI: Tailwind + shadcn

Follow `design-system/MASTER.md` and `design-system/pages/` overrides.

- Primitives from `src/components/ui` (Button, Input, Label, Card, Separator, Sonner).
- Missing component: `npx shadcn@latest add <name>`.
- No parallel CSS (`btn-primary`, CSS modules for layout).
- Lucide or brand SVGs — no emoji icons.
- Visible `Label` on every field; async buttons `disabled` + loading text.
- Toaster in root layout only.
